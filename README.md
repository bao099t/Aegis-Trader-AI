## 📖 Introduction
**The Sentinel** has evolved into the **Hybrid Arsenal 2.0**—a high-intelligence trading engine that combines the armor of a fortress with the precision of a sniper.

Built on a **"Safety First"** philosophy, the system now utilizes **Generative AI** and **Machine Learning** to dominate both trending and sideways markets.

### Why does this project exist?
Most traders lose money not because they lack technical analysis skills, but because they fail to adapt to changing market regimes. Sentinel Hybrid 2.0 solves this by automatically switching between **Trend Hunting** and **Mean Reversion** while being guarded by an unshakeable AI logic.

---

## 🌟 Key Features

### 1. 🤖 AI Price Predictor (Intelligence Layer)
*   **Machine Learning**: Uses a Random Forest model trained on 10+ years of indicators.
*   **NLP Sentiment**: Real-time news analysis using VADER and TextBlob to "read" market mood.
*   **AI Guardian**: Blocks trades if price prediction contradicts the technical signal.

### 2. 🏹 Multi-Strategy Engine (The Conductor)
*   **Trend Hunter**: Captures massive moves (ADX > 25) in bull/bear markets.
*   **Mean Reversion (Sniper)**: Profits from sideways markets (ADX < 20) using Bollinger Bands & RSI.
*   **Dynamic Switching**: Automatically adjusts strategy based on the Market Regime.

### 3. 🛡️ The Sovereign Guardian & Phoenix Protocol
*   **Guardian**: Supreme veto power. Never allows trade size > **15%**.
*   **Phoenix**: Automatically switches to **Paper Trading** during losing streaks, resurrecting only after a proven win streak.

## 🛠️ Installation

### Requirements
*   Python 3.9+
*   Discord Account (for Alerts)

### Instructions
1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/the-sentinel.git
    cd the-sentinel
    ```

2.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Configuration**:
    *   Open `src/delivery/discord_webhook.py` and paste your Discord Webhook URL.

4.  **Run the application**:
    ```bash
    python src/main.py
    # Or run run_app.bat on Windows
    ```
